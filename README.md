## 🚀 Featured Project — Disaster Impact Prediction System

**Objective:**  
A Flask-based AI system that predicts the impact of disasters (fatalities, severity, property loss) using real-time and historical data for multiple disaster classes such as:
- 🌍 Earthquakes
- ✈ Aviation incidents
- 🏭 Industrial accidents
- 🌋 Wildfires

**Key Features:**
- 🔹 **Multi-model architecture** — separate models for each disaster type  
- 🔹 **Real-time data fetching** (via APIs or simulated feeds)  
- 🔹 **Impact prediction** (casualties, severity levels, and loss estimates)  
- 🔹 **Visualization dashboard** (interactive charts, filters, search)  
- 🔹 **Exportable reports** (CSV format)  

**Tech Stack:**
- **Backend:** Python, Flask  
- **ML:** scikit-learn, Pandas, NumPy  
- **Database:** MongoDB  
- **Visualization:** Matplotlib, Plotly  
- **Deployment:** Flask server
